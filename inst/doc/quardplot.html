Getting started with quardplot

quardplot makes aligned locus figures and tables from GWAS results, a gene annotation (GFF3 or GTF) and genotypes (VCF or HapMap). This vignette runs the main steps on a small simulated rice data set. For a longer, step-by-step guide with your own files, run quard_guide(): it copies the guide quard_plot_examples.R into your folder.

1. Choose the species

The species gives the chromosome lengths of the reference genome for the genome-wide plots.

library(quardplot)
list_species()[, c("species", "reference_genome", "chromosomes")]
#>        species          reference_genome chromosomes
#> 1         rice          IRGSP-1.0 / MSU7          12
#> 2  arabidopsis                    TAIR10           5
#> 3       tomato SL4.0 (ITAG4.0 / ITAG4.1)          12
#> 4        human             GRCh38 / hg38          24
#> 5 human_grch37             GRCh37 / hg19          24
#> 6        mouse             GRCm39 / mm39          21
#> 7 mouse_grcm38             GRCm38 / mm10          21
set_species("rice")
#> Species: Rice (Oryza sativa, Nipponbare) - reference genome IRGSP-1.0 / MSU7 (12 chromosomes, 373.2 Mb; lengths: built-in).
#> All plots now use these chromosome lengths. Your GWAS, genotype (VCF/HapMap) and GFF files must use the same reference genome.

For a species that is not built in, give its chromosome lengths, for example set_species("pepper", chrom_sizes = "pepper_genome.fa.fai").

The tables are written next to the PDF. The SNP table gives, for every GWAS SNP in the region, its P value, its r2 with the lead SNP and where it lies relative to the nearest gene:

Panels and tables are chosen independently, so the LD table can be written without the heatmap, or tables can be written without any figure:

r2 <- quard_plot(my$gwas, my$gff, my$vcf, chr = ex$chr, pos = ex$pos,
                 panels = c("regional", "genes"), tables = c("snps", "ld"),
                 output = file.path(out, "locus_no_heatmap.pdf"), verbose = FALSE)
names(r2$files)
#> [1] "pdf"       "snps"      "ld_matrix" "readme"

With table_format = "xlsx" (needs the writexl package) all tables are put in one Excel file with a README sheet.
